# Dify 知识库检索与问答

## 配置

```env
DIFY_BASE_URL=http://127.0.0.1:5001/v1
DIFY_API_KEY=dataset-xxxx
DIFY_DATASETS=投诉口径:uuid1,网络口径:uuid2
DIFY_DATASET_DEFAULT=投诉口径
```

- `dataset` 填库**名称**，不要填 UUID。
- 留空 → 查 `DIFY_DATASET_DEFAULT`。
- **查两个库**：对本工具调用两次，换不同 `dataset`（不要一次传多个名）。

## 检索

```
search_dify_kb(query="用户问题原文", dataset="投诉口径")
search_dify_kb(query="用户问题原文")  # 默认库
```

- 每个问题对同一库只查一次；`top_k=4`。
- 时间/城市等限定词一次写进 query。

## 回答

- **只依据检索结果**，禁止编造知识库未返回的指标定义、数字或时间口径。
- **未指定日期 → 只答最近一期**：用户未给出具体年月/起止时（含「最近」「最近一月」「情况如何」等），在检索命中的多段里只选用**文档时间最新**的那一期作答；不要把更早文档一并列出。
- **必须标明文档时间，但要简洁**：开篇一行即可，例如 `数据时段：2026-05-01～2026-05-31` 或 `数据时段：2026年5月`。优先用工具返回的「文档时间」；不要罗列来源文件名（如 `xxx.md`），不要写「期间（来源文档：…）」这种冗长句式。
- 用户明确指定了某月/区间时，才按该时段作答；若库中无该时段，说明暂无并询问是否改走数据分析。
- 无匹配则说「暂无此结果」，并询问是否改走数据分析。同一轮不要委派，等用户下一句同意。
- 城市数据可用表格。
- 涉及业务库统计/重投数字时不要用本 skill 瞎估；应走 analytics（重投表时间字段为 **派单时间**）。
- 总字数 ≤400；勿暴露 UUID。
